# 电子书检索场景契约 v0.1

> 架构·产品 | 2026-09-04

## 场景定位

个人能力中枢的 **首个落地场景（MVP）**：多版本电子书检索。

## 用户故事

> As a 需要特定电子版教材的用户
> I want 输入书名+作者+版本等条件，自动搜索并找到匹配的电子书资源
> So that 不需要自己逐个网站手动查找

## 业务规则

### 输入
自然语言描述，例如：
> "找《物理学基础》哈里德著的电子版，第6版中文版（张三慧翻译）或第10/12版英文extended版"

### 处理
1. 解析书名/作者/版本/语言/规格等字段
2. 对版本进行消歧（第6版中文版 vs 第10/12版英文extended版）
3. 多源搜索（搜索引擎+已知电子书源站）
4. 验证命中结果（资源可用性/版本匹配/规格符合）
5. 排序返回

### 输出
- 命中资源列表（含来源、格式、URL、置信度）
- 未确认的版本（标记待确认）
- 无结果时明确说明

## 成功指标

| 指标 | 目标 |
|------|------|
| 查询成功率（有资源且找到） | ≥ 80%（优秀 ≥ 90%） |
| 平均查询耗时 | ≤ 60 秒 |
| 无结果误报（有却说没有） | 尽可能低 |
| 人工介入率 | 越低越好 |

## 失败分类

| 分类 | 说明 | 判定 |
|------|------|------|
| NOT_FOUND | 搜索完成但零命中 | 3来源×2轮 后零结果 |
| NOT_MATCHED | 有命中但版本/规格不符 | 命中验证不通过 |
| UNVERIFIED | 找到但无法确认可用 | 链接可达性探测失败 |
| TIMEOUT | 超过搜索时限 | >60秒 |

## 人工兜底触发

仅在以下情况触发人工：
1. 自动搜索全部失败（NOT_FOUND + NOT_MATCHED）
2. 用户主动要求人工帮助
3. 版本信息极度模糊无法解析

## 非目标（明确不做）

- 不做资源下载/存储（只提供定位）
- 不做全网资源数据库（来源不归属本系统）
- 不做版权判定（用户自行判断合法性）
