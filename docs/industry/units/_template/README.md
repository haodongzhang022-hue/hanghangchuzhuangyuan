## 四、路由接入方式

上层 Agent 将用户诉求文本送入通用能力层路由（`route`），由 M1 按**行业 → 岗位**两级识别自动路由至本行业对应岗位。行业锁定后单会话不跨行业（SLIB）。

```bash
python3 src/hanghang/cli/main.py route "<用户诉求文本>"
```

## 五、使用约束

- **会话级行业绑定（SLIB）**：一个 session 绑定一个行业，会话内不得切换行业；跨行业需新开会话 + 交接卡。
- **复合装配**：本行业内多岗位可同会话复合（前缀取本行业稳定前缀集）。
- **跨行业交接**：经 M5 交接总线建 HandoffCard 接力，不做同会话拼接。
