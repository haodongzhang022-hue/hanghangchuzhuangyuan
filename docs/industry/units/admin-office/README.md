# 行政办公 · Agent 使用说明

> 本说明面向需要对接/调用本行业能力的上层 **AI Agent**（路由 / 编排 / 下游执行 Agent）。
> 通过通用能力层知识库检索可注入 Agent 提示词。数据同步自 `data/unit-index.yaml`（unit_id=`admin-office`）。

## 一、行业定位

- **unit_id**：`admin-office`
- **行业标签**：行政办公
- **行业别名**：行政、行政办公、行政专员、办公、行政事务、办公室、文秘、公文、后勤、前台、行政管理
- **入口地址**：_集中本仓，repo_ref 待回填_

> 本行业面向 **行政办公** 相关诉求。上层路由 Agent 依据行业别名与关键词自动识别并路由至此行业。

## 二、能力范围

- 行政事务
- 前台接待
- 公文写作
- 档案文书
- 会务组织
- 办公采购
- 差旅安排
- 后勤管理

## 三、可路由岗位

| 岗位 | 前缀 | 职责 | 典型触发词（示例） |
|------|------|------|-------------------|
| admin_specialist | [行政专员] | 行政事务 办公用品 办公环境 日常行政 后勤 | 行政、行政专员、行政事务、行政管理、日常行政、办公用品、办公用品采购、采购办公用品 |
| receptionist | [前台] | 前台接待 访客接待 来电接听 指引 | 前台、前台接待、接待、接待访客、访客登记、访客、来宾接待、客户接待 |
| document_archivist | [档案文书] | 公文写作 文件起草 档案管理 资料归档 文书 | 公文、公文写作、写公文、通知、通告、函、会议纪要、会议记录 |
| meeting_coordinator | [会务] | 会议组织 会务 差旅安排 团建活动 接待安排 | 会议组织、会议安排、组织会议、安排会议、会务、会务安排、会场布置、会议筹备 |

> 岗位说明：单会话内绑定本行业后，可按需路由到上述任一岗位；同一行业的多岗位可复合装配。

## 四、路由接入方式

将用户诉求文本送入通用能力层路由（`route`），由 M1 按 **行业 → 岗位** 两级识别自动路由至本行业。

```bash
python3 src/hanghang/cli/main.py route "<诉求文本>"
# 指定会话（SLIB：首次路由自动绑定本行业）
python3 src/hanghang/cli/main.py route "<诉求文本>" --session "<session_id>"
```

## 五、使用约束

- **会话级行业绑定（SLIB）**：一个 session 绑定一个行业，会话内不得静默跨行业；跨行业诉求触发交接（需新会话）。
- **稳定前缀**：本行业岗位前缀为 `[行政专员]、[前台]、[档案文书]、[会务]`，会话内稳定不变。
- **跨行业交接**：经 M5 交接总线建 HandoffCard 接力，不做同会话拼接。
