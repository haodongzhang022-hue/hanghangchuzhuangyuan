# 内容创作 · Agent 使用说明

> 本说明面向需要对接/调用本行业能力的上层 **AI Agent**（路由 / 编排 / 下游执行 Agent）。
> 通过通用能力层知识库检索可注入 Agent 提示词。数据同步自 `data/unit-index.yaml`（unit_id=`content-creation`）。

## 一、行业定位

- **unit_id**：`content-creation`
- **行业标签**：内容创作
- **行业别名**：内容创作、新媒体、文案、自媒体、短视频、公众号、内容运营
- **入口地址**：_集中本仓，repo_ref 待回填_

> 本行业面向 **内容创作** 相关诉求。上层路由 Agent 依据行业别名与关键词自动识别并路由至此行业。

## 二、能力范围

- 文案策划
- 内容运营
- 短视频脚本
- 新媒体运营
- 品牌内容
- 图文编辑

## 三、可路由岗位

| 岗位 | 前缀 | 职责 | 典型触发词（示例） |
|------|------|------|-------------------|
| copywriter | [文案] | 品牌文案 广告文案 卖点文案 技术博客 博客文章 | 写文案、品牌文案、广告文案、文案策划、卖点文案、营销文案 |
| media_operator | [新媒体] | 公众号运营 短视频运营 账号运营 | 新媒体运营、公众号、公众号运营、短视频、短视频运营、账号运营 |
| content_editor | [编辑] | 稿件审校 内容排版 文章润色 | 内容编辑、稿件审校、内容排版、文章润色、图文编辑、审校 |

> 岗位说明：单会话内绑定本行业后，可按需路由到上述任一岗位；同一行业的多岗位可复合装配。

## 四、路由接入方式

将用户诉求文本送入通用能力层路由（`route`），由 M1 按 **行业 → 岗位** 两级识别自动路由至本行业。

```bash
python3 src/hanghang/cli/main.py route "<诉求文本>"
# 指定会话（SLIB：首次路由自动绑定本行业）
python3 src/hanghang/cli/main.py route "<诉求文本>" --session "<session_id>"
```

## 五、使用约束

- **会话级行业绑定（SLIB）**：一个 session 绑定一个行业，会话内不得静默跨行业；跨行业诉求触发交接（需新会话）。
- **稳定前缀**：本行业岗位前缀为 `[文案], [新媒体], [编辑]`，会话内稳定不变。
- **跨行业交接**：经 M5 交接总线建 HandoffCard 接力，不做同会话拼接。
