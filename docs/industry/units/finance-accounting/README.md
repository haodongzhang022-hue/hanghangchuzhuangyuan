# 财务会计 · Agent 使用说明

> 本说明面向需要对接/调用本行业能力的上层 **AI Agent**（路由 / 编排 / 下游执行 Agent）。
> 通过通用能力层知识库检索可注入 Agent 提示词。数据同步自 `data/unit-index.yaml`（unit_id=`finance-accounting`）。

## 一、行业定位

- **unit_id**：`finance-accounting`
- **行业标签**：财务会计
- **行业别名**：财务、会计、记账、报税、做账、报销、纳税、税务、工资核算、财务分析、会计核算、出纳、财务报表、账务
- **入口地址**：_集中本仓，repo_ref 待回填_

> 本行业面向 **财务会计** 相关诉求。上层路由 Agent 依据行业别名与关键词自动识别并路由至此行业。

## 二、能力范围

- 记账
- 报税
- 报销
- 财务报表
- 会计核算
- 税务申报

## 三、可路由岗位

| 岗位 | 前缀 | 职责 | 典型触发词（示例） |
|------|------|------|-------------------|
| accountant | [会计] | 记账 做账 会计 账务处理 凭证 | 记账、做账、会计、账务处理、凭证、记账本 |
| tax_advisor | [税务] | 报税 税务申报 纳税筹划 个税 企业所得税 | 报税、税务、纳税、个税、税、企业所得税 |
| finance_analyst | [财务分析] | 财务报表 财务分析 成本分析 利润分析 | 财务报表、财务分析、成本核算、成本分析、利润分析、财务报告 |
| payroll_processor | [薪酬] | 工资核算 社保公积金 薪酬管理 | 工资核算、工资、社保、公积金、薪酬、薪资 |

> 岗位说明：单会话内绑定本行业后，可按需路由到上述任一岗位；同一行业的多岗位可复合装配。

## 四、路由接入方式

将用户诉求文本送入通用能力层路由（`route`），由 M1 按 **行业 → 岗位** 两级识别自动路由至本行业。

```bash
python3 src/hanghang/cli/main.py route "<诉求文本>"
# 指定会话（SLIB：首次路由自动绑定本行业）
python3 src/hanghang/cli/main.py route "<诉求文本>" --session "<session_id>"
```

## 五、使用约束

- **会话级行业绑定（SLIB）**：一个 session 绑定一个行业，会话内不得静默跨行业；跨行业诉求触发交接（需新会话）。
- **稳定前缀**：本行业岗位前缀为 `[会计], [税务], [财务分析], [薪酬]`，会话内稳定不变。
- **跨行业交接**：经 M5 交接总线建 HandoffCard 接力，不做同会话拼接。
