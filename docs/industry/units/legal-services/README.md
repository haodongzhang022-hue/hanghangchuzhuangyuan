# 法律咨询 · Agent 使用说明

> 本说明面向需要对接/调用本行业能力的上层 **AI Agent**（路由 / 编排 / 下游执行 Agent）。
> 通过通用能力层知识库检索可注入 Agent 提示词。数据同步自 `data/unit-index.yaml`（unit_id=`legal-services`）。

## 一、行业定位

- **unit_id**：`legal-services`
- **行业标签**：法律咨询
- **行业别名**：法律、律师、法务、诉讼、打官司、知识产权、劳动仲裁、合同、劳动合同、劳动纠纷、知识产权保护、著作权、软件著作权、版权
- **入口地址**：_集中本仓，repo_ref 待回填_

> 本行业面向 **法律咨询** 相关诉求。上层路由 Agent 依据行业别名与关键词自动识别并路由至此行业。

## 二、能力范围

- 合同审查
- 法律意见
- 诉讼代理
- 企业法务
- 知识产权保护
- 合规审查

## 三、可路由岗位

| 岗位 | 前缀 | 职责 | 典型触发词（示例） |
|------|------|------|-------------------|
| legal_counsel | [律师] | 诉讼代理 法律意见 应诉 起草起诉状 | 诉讼代理、法律意见、打官司、应诉、起草起诉状、法律咨询 |
| contract_advisor | [合同] | 合同审查 合同条款 起草合同 | 合同审查、审合同、合同条款、起草合同、审查合同、劳动合同 |
| compliance_advisor | [合规] | 合规审查 法规遵从 政策合规 | 合规审查、法规遵从、政策合规、反垄断合规、数据合规 |

> 岗位说明：单会话内绑定本行业后，可按需路由到上述任一岗位；同一行业的多岗位可复合装配。

## 四、路由接入方式

将用户诉求文本送入通用能力层路由（`route`），由 M1 按 **行业 → 岗位** 两级识别自动路由至本行业。

```bash
python3 src/hanghang/cli/main.py route "<诉求文本>"
# 指定会话（SLIB：首次路由自动绑定本行业）
python3 src/hanghang/cli/main.py route "<诉求文本>" --session "<session_id>"
```

## 五、使用约束

- **会话级行业绑定（SLIB）**：一个 session 绑定一个行业，会话内不得静默跨行业；跨行业诉求触发交接（需新会话）。
- **稳定前缀**：本行业岗位前缀为 `[律师], [合同], [合规]`，会话内稳定不变。
- **跨行业交接**：经 M5 交接总线建 HandoffCard 接力，不做同会话拼接。
