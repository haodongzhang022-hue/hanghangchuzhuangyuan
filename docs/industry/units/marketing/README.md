# 市场营销 · Agent 使用说明

> 本说明面向需要对接/调用本行业能力的上层 **AI Agent**（路由 / 编排 / 下游执行 Agent）。
> 通过通用能力层知识库检索可注入 Agent 提示词。数据同步自 `data/unit-index.yaml`（unit_id=`marketing`）。

## 一、行业定位

- **unit_id**：`marketing`
- **行业标签**：市场营销
- **行业别名**：市场营销、市场策划、市场推广、品牌战略、广告投放、品牌策划、公关策划、营销策略、市场方案、商业计划、商业策划、推广策划、营销推广、市场部、营销部、活动企划
- **入口地址**：_集中本仓，repo_ref 待回填_

> 本行业面向 **市场营销** 相关诉求。上层路由 Agent 依据行业别名与关键词自动识别并路由至此行业。

## 二、能力范围

- 品牌策划
- 市场调研
- 活动策划
- 推广方案
- 广告投放
- 公关管理
- 营销方案

## 三、可路由岗位

| 岗位 | 前缀 | 职责 | 典型触发词（示例） |
|------|------|------|-------------------|
| market_researcher | [调研] | 市场调研 竞品分析 用户调研 行业分析 | 市场调研、竞品调研、竞品分析、用户调研、行业分析、市场分析 |
| brand_planner | [品牌策划] | 品牌策划 品牌定位 品牌方案 | 品牌策划、品牌定位、品牌方案、品牌设计、品牌战略、品牌故事 |
| campaign_planner | [活动策划] | 活动策划 营销方案 推广策划 活动方案 营销策划 | 市场营销策划、营销策划、活动策划、活动方案、推广策划、推广方案 |
| pr_manager | [公关] | 公关 媒体关系 品牌传播 新闻稿 | 公关、媒体关系、品牌传播、新闻稿、危机公关、发布会 |

> 岗位说明：单会话内绑定本行业后，可按需路由到上述任一岗位；同一行业的多岗位可复合装配。

## 四、路由接入方式

将用户诉求文本送入通用能力层路由（`route`），由 M1 按 **行业 → 岗位** 两级识别自动路由至本行业。

```bash
python3 src/hanghang/cli/main.py route "<诉求文本>"
# 指定会话（SLIB：首次路由自动绑定本行业）
python3 src/hanghang/cli/main.py route "<诉求文本>" --session "<session_id>"
```

## 五、使用约束

- **会话级行业绑定（SLIB）**：一个 session 绑定一个行业，会话内不得静默跨行业；跨行业诉求触发交接（需新会话）。
- **稳定前缀**：本行业岗位前缀为 `[调研], [品牌策划], [活动策划], [公关]`，会话内稳定不变。
- **跨行业交接**：经 M5 交接总线建 HandoffCard 接力，不做同会话拼接。
